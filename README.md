## ABOUT THE ARCHIVES

**The Hollow Archives** is a community-driven collection of media, discoveries, and solved puzzles surrounding the alternate reality game (ARG) behind the band **Hiraeth**.

Created to document and preserve the unfolding mystery, this repository serves as a centralized archive of the story hidden across music, websites, imagery, cryptic messages, and other media.

## WHAT'S INSIDE

- **The Prologue** — Starts with HIRAETH in November 2025 and moves through VESTIGE, ANIMA, MIRROR, SANCTUARY, EREMITIS, EXSILIUM, SIGILS, CLOUDS, and Windows.
- **Chapter 1** — Contains Threshold, RECORD, CLAIM, MOTION, SEVER, and LARKSPUR, along with investigations into Oracle Echo, the Sanctuary Map, and VESTIGE.
- **Decoding Tools** — Includes sigil reference material and common cipher decoding tools.
- **Live Events & Other Evidence** — Includes the WITNESS event, Cerulean, and archived social-media evidence.

## EXPLORING THE ARCHIVES

The archive is maintained as an [Obsidian](https://obsidian.md/) vault, using interconnected Markdown notes to organize discoveries and establish relationships between clues.

For the intended browsing experience, explore the published archive:

**[ENTER THE HOLLOW ARCHIVES](https://publish.obsidian.md/ynhyae/Welcome)**

Alternatively, clone this repository and open the vault locally using Obsidian.

## CONTRIBUTING

The Hollow Archives is an ongoing effort. As new material surfaces and puzzles are solved, the archive will continue to evolve.

Contributions, corrections, and additional discoveries are welcome through GitHub Issues and Pull Requests.

When contributing, please distinguish between **confirmed information, interpretations, and unverified theories**. Wherever possible, include the original source of a discovery so that others can independently examine the evidence.
